# Fintech Wallet

A Java Fintech Training Project — User, Wallet, Transfer & MySQL.

## Features
- Create User with Wallet
- Transfer money between users
- Save users and wallets to MySQL database
- View balance

## Technologies
- Java (NetBeans)
- MySQL
- Git / GitHub

## How To Run
1. Create MySQL database `fintech_db`
2. Update DB username/password in `Database.java`
3. Run `Main.java` in NetBeans
